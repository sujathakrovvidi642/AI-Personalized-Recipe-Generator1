# AI Personalized Recipe Generator 🍳

## Description
AI Personalized Recipe Generator is a Flask-based application that generates personalized recipes based on user preferences like available ingredients, cuisine type, dietary preferences, cooking time, and skill level.

## Features

- Add available ingredients
- Select cuisine preference
- Choose dietary preferences
- Set cooking time
- Select cooking skill level
- Generate personalized recipes using AI
- Structured recipe output

## Technologies Used

- Python
- Flask
- HTML
- CSS
- Generative AI
- API Integration
